HeadVR (https://github.com/autoandshare/HeadVR) is an open source VR video player based on VLC.

Features   Usage

Features:
  • 2D, 180 and 360 degree video, mono, side-by-side and top-bottom, including fisheye 180 projections (equidistant and equisolid)
  • Layout auto-detected from file name tags: sbs, hsbs, fsbs, ou, tab, tb, lr, 180, 360, fisheye, mkx200, equisolid
  • Hardware decoding with automatic software fallback for files that fail to play
  • Touch control, bluetooth controller and head motion control
  • Head control may be disabled or locked
  • Head cursor (gaze control): a dot shows where you look; hold it on a button or the progress bar for 2 seconds to click, no controller needed
  • Recenter button on the control bar to reset the forward direction of 180/360 video (same as double-tapping the screen)
  • A dedicated stream URL box and a history list with a delete button on every entry; URLs are checked before the player opens
  • Default video format setting (for example side-by-side 180) used when the file name has no format tags
  • Optionally pauses automatically when you take the headset off
  • Local and network (SMB, FTP, HTTP ...) resources
  • Curated HeadVR Channel and a stream URL history
  • Rich settings (brightness, eye distance, video size, video position ...)
  • Video Options: layout/aspect override, fisheye projection, audio track, subtitle track, software decoding, playback speed, audio and subtitle delay
  • Force2D mode to make some 3D video more comfortable. In this mode, the same picture is shown to both eyes.
  • Automatic selection of audio track and subtitle based on language keywords in settings
Note:
  • Gyroscope sensor is necessary for head control
  • 3D/VR file names may include tags like sbs, hsbs, fsbs, ou, tab, tb, lr, 180, 360, fisheye, mkx200, equisolid to indicate their format
  • The Video Options screen shows the mode detected from the file name and lets you override it for the current video
  • The settings screen has a "Default video format" option used for videos whose file name does not contain format tags
  • To get a good experience, be sure to adjust the headset and the eye distance setting so that the inter-lens distance and the video distance on the phone screen are the same as your interpupillary distance


Usage:

Touch Control:

Play/Pause - Touch right 2/3 of the screen
Forward/Rewind - Swipe right/left
Next/Prev Video - Swipe up/down
Video Options - Touch left 1/3 of the screen
Recenter 360/180 Video - Double tap the screen

Streams:

Play a saved URL - Tap it in the history list, or paste a URL and press Play. The URL is checked first; when it is ready, press the Ready button to open the video
Edit / Remove - Press the X button on the right of a saved URL, or long-press it

Head Cursor (Gaze Control):

Show controls - Look down; the control bar appears in front of you
Click a button - Hold the cursor on it for 2 seconds
Seek - Hold the cursor on the progress bar at the position you want
Recenter 360/180 video - Hold the cursor on the ↻ button

Bluetooth Controller:

Play/Pause - Center key
Forward/Rewind - Right/left key
Next/Prev Video - Down/up key

Head Control:

There are 5 basic head motions: Up, Down, Left, Right, Hold still. Each function is a combination of these motions.

Play/Pause - Down, Up (nod)
Forward - Right, Hold still, Left (cancel with Up/Down)
Rewind - Left, Hold still, Right (cancel with Up/Down)
Next Video - Up, Down, Right, Left
Prev Video - Up, Down, Left, Right
Lock Head Control - Up, Right, Left, Down
Recenter 360/180 Video - Left, Right, Left, Right
Toggle Force2D mode - Right, Left, Right, Left

Note:
Seeking is only enabled for 360/180 video when it is paused.
